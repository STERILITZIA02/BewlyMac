## 文档约定

- 文档以简体中文为主，命令、文件名和必要技术术语保留英文；
- 命令必须与 `package.json` 中的脚本保持一致；
- 一次性实施计划不进入长期文档；
- 同一流程只维护一个权威入口，避免复制后逐渐失效。
