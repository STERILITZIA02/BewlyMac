# BewlyCat

此项目基于[BewlyBewly](https://github.com/BewlyBewly/BewlyBewly) 和开发[BewlyCat](https://github.com/keleus/BewlyCat)，并在其基础上进行功能扩充和调整，并合并了一些其他拓展的功能。

> [!IMPORTANT]
> 本插件及Fork代码禁止以任何形式的客户端封装
> 欢迎功能建议与bug反馈，本分支是一个较大规模视觉及交互重构的basement。
> 浏览器拓展商店上架正在计划中。
> 本项目由MIT许可在原项目基础上开发。
